# Sample Data

This directory stores binary stream files generated by PROTOCORE.

## Expected Format

Binary files in this directory should contain raw bytes in the PROTOCORE packet format:

| Field | Size | Description |
|---|---:|---|
| Start Signature | 4 bytes | `AA BB CC DD` |
| Payload Length | 2 bytes | Big-endian uint16 |
| Payload | Variable | Actual data |
| CRC-32 | 4 bytes | Big-endian CRC-32/ISO-HDLC |
| End Marker | 2 bytes | `EE FF` |

## Generating Sample Files

Use PROTOCORE's **Menu Option 1** (Generate Sample Network Stream) to create sample binary files. The application will offer to save the generated stream to this directory.

## Loading Files

Use **Menu Option 2** (Load Binary Stream from File) and provide the path to any `.bin` file in this directory.
